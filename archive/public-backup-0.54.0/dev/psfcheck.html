ARCNAVE PSF vs the official SPHEREx PSF (developer check)

Field RA 189.957, Dec -4.182, the 24 demo images. For each image: the pipeline's own PSF (PSF extension, zone of this spot, 10x oversampled) is placed on the native detector pixels and sent through ARCNAVE's own resampling, so it can be compared like for like with the real stars and with ARCNAVE's measured PSFs. "Shape" = light in the 4 neighbours / 4 x peak (lower = sharper). Nothing here is shown to the public.
